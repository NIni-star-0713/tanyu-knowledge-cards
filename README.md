# 探域商品知识卡生成器

把商品详情页、SKU截图和商家确认信息，整理成可复制到 **探域 Agent Builder** 的中文客服知识卡。

这是一个 Agent Skill：核心文件是 [SKILL.md](SKILL.md)，不是探域官方插件，也不会自动登录店铺或调用探域API。适合支持本地Skills和图片阅读的AI助手使用。

## 可以做什么

- 核对商品事实，区分已确认、缺失和冲突信息。
- 规划商品分组、FAQ主题和意图分段。
- 生成固定回复数量、短句话术及输出限制。
- 区分售前、售后、不适反馈，减少多卡抢答和重复转接。
- 规划教程图、商品卡映射和平台测试问题。

## 使用

将仓库下载为ZIP并解压，把含有 `SKILL.md` 的文件夹命名为 `build-tanyu-knowledge-cards`，放入你的AI工具支持的Skills目录。

Codex可使用个人技能目录 `~/.codex/skills/build-tanyu-knowledge-cards/`。Windows的 `~` 表示当前用户目录。若已有同名技能，先备份，或在隔离目录试用，不直接覆盖你的定制版本。

调用示例：

```text
使用 $build-tanyu-knowledge-cards 分析这些商品详情页。
请先列出确认事实与缺失信息，再给出分组建议、完整探域知识卡和测试问题。
未确认的规格、功效和售后政策不要编造。
```

## 你需要准备

商品详情页/包装/SKU截图，当前分组（如有），实际店铺商品卡映射，以及你允许执行的售后政策。缺少商品映射时只会输出待补位置，不会声称已发送商品卡。

查看 [EXAMPLE.md](EXAMPLE.md) 了解输出样式，里面全部是虚构练习资料。

## 使用边界

- 公开版不含真实店铺商品档案、内部退款方案、客户记录、密钥或私人路径；本机定制版应独立保留。
- 平台界面、气泡分段、学习机制和字段上限可能随版本变化，必须在你自己的账号实测。
- 模型不能保证逐字输出，知识卡上线前需验证回复数量、事实和检索来源。
- 本仓库未在所有探域版本进行测试；发布时只做结构、格式、占位符和公开内容检查，没有操作真实店铺。
- 不提供医疗诊断，不替商家承诺退款、赔偿或商品功效。

## 反馈与贡献

欢迎通过Issue提交脱敏的错误案例：说明输入类型、期望输出、实际输出和可复现步骤。不要上传买家姓名、电话、地址、订单号、内部账号、密钥或未授权的商品图片。
